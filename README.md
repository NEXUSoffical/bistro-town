# ☕ Bistro Town

> A cozy isometric restaurant simulation game with real-time cloud saving, staff hiring, and cooking mastery.

## Features
- 🏗️ **Isometric Restaurant Builder**: Place stoves, tables, chairs, doors, windows, and decor.
- 🧑‍🍳 **Staff Management**: Hire and manage chefs, waiters, and cleaners with shifts and payroll.
- 🥣 **Cookbook & Mastery**: Unlock and upgrade gourmet recipes across starters, mains, desserts, and drinks.
- ☁️ **Dual-Layer Cloud Save**: Instant 0ms local storage with background sync to Supabase Cloud and Google Sign-In.
- 📊 **Tycoon Finances**: Shift balance sheets, profit & loss statements, and advisor insights.

## Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
